# javanote

Учебное приложение для заметок, практика по книге *Craig Walls — Spring in Action*
(Manning, 2018). REST API (JWT) для мобильных клиентов, Web MVC (Thymeleaf, сессии) для
веба, гибридная персистентность (PostgreSQL + MongoDB), кэш (Caffeine → Redis), отдельный
push-сервис на Kafka + Firebase Cloud Messaging, деплой в k3s.
