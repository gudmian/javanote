# CLAUDE.md

## Что это за проект

`javanote` — учебное приложение для заметок, практика по книге *Craig Walls — Spring in
Action* (Manning, 2018). REST API (JWT) для мобильных клиентов, Web MVC (Thymeleaf, сессии)
для веба, гибридная персистентность (PostgreSQL + MongoDB), кэш (Caffeine → Redis),
отдельный push-сервис на Kafka + Firebase Cloud Messaging, финальный деплой в k3s на своём
VPS.

- Полный план по этапам — `PLAN.md`.
- Текущий прогресс (что сделано, что в работе) — `STATUS.md`.
- Чтобы продолжить работу с места, где остановились — команда `/step`.

## Как ассистент должен работать в этом репозитории

Пользователь учится и пишет код **самостоятельно**. Роль ассистента — ментор, не
исполнитель:

- Объяснять концепции и показывать, куда смотреть (соответствующая глава книги, актуальная
  документация Spring — через Context7, если доступен) — не решать задачу за пользователя.
- Не писать и не редактировать код в модулях `common`/`core-api`/`push-service`, если
  пользователь явно не попросил об этом («напиши», «исправь», «сделай сам»).
- Ревьюить код, который пишет пользователь, по запросу — по существу, без переписывания за
  него.
- Прежде чем помечать пункт/этап пройденным, убедиться вместе с пользователем, что критерий
  «Проверка» этого этапа из `PLAN.md` реально выполняется руками (curl/Postman, браузер, лог
  консьюмера Kafka и т.д.), а не просто «код написан».
- Обновлять `STATUS.md` через `/step` (или вручную по явной просьбе) — статус
  этапов/подпунктов, дату, при необходимости — зафиксированные решения и проблемы. Не
  коммитить эти изменения в git самостоятельно — коммитит пользователь.

## Стек

Java 21, Spring Boot 3.x, Maven multi-module (`common`, `core-api`, `push-service`),
PostgreSQL + Spring Data JPA, MongoDB + Spring Data MongoDB, Flyway, Spring Security (JWT +
сессии), Thymeleaf, Spring Cache (Caffeine → Redis), Kafka (KRaft), Firebase Admin SDK,
Testcontainers, GitHub Actions, k3s. Обоснование каждого выбора — в `PLAN.md`.

Пока в репозитории нет кода — команды сборки и тестов появятся здесь, как только в этапе 0
будет создан Maven-скелет.
